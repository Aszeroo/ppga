LESSON 03 · MODULE 02

🎯 จุดประสงค์การเรียน

เข้าใจว่า Theme คืออะไร และเลือกใช้ Theme กับ PowerPoint ได้อย่างเหมาะสมกับงาน

💡 ทำไมเรื่องนี้สำคัญ

Theme ช่วยให้สไลด์ดูเป็นระเบียบ สม่ำเสมอ และน่าเชื่อถือ — เหมาะกับงานจริงทุกวิชา

📚 เนื้อหาบทเรียน

Theme คือชุดสี ฟอนต์ และพื้นหลังที่ออกแบบมาให้เข้ากัน แทนการจัดแต่งทีละสไลด์ เราเลือก Theme เดียวแล้วทุกสไลด์จะสวยพร้อมกันหมด

  • 1ไปที่แท็บ Design ด้านบน
  • 2วางเมาส์บน Theme แต่ละแบบเพื่อดูตัวอย่าง
  • 3คลิกเลือก Theme ที่ชอบ — สี/ฟอนต์ทั้งเล่มเปลี่ยนทันที
  • 4ลอง Variants ด้านขวาเพื่อสลับโทนสีย่อย
🖼️

ตัวอย่าง: การเลือก Theme บนแท็บ Design ใน PowerPoint

💡 เคล็ดลับ

เลือก Theme ก่อนใส่เนื้อหา จะประหยัดเวลาจัดแต่งมากขึ้น

⚠️ ข้อควรระวัง

อย่าสลับ Theme บ่อย ๆ หลังใส่เนื้อหา — ข้อความอาจเพี้ยนได้
