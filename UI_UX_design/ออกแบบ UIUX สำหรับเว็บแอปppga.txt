ออกแบบ UI/UX สำหรับเว็บแอปพลิเคชันชื่อ **PPGA — PowerPoint Gamified Learning**

## 1. Product Context

PPGA เป็นเว็บแอปพลิเคชันสำหรับการเรียนรู้การสร้างงานนำเสนอด้วย Microsoft PowerPoint โดยใช้แนวคิด Gamification สำหรับนักเรียนระดับประกาศนียบัตรวิชาชีพชั้นปีที่ 2 (ปวช.2)

เป้าหมายหลักของ UI:

* ทำให้นักเรียนรู้สึกเหมือนกำลังเล่นเกมการเรียนรู้
* แต่ยังคงความเป็นระบบการเรียนรู้จริง
* ทุกหน้าต้องชัดเจนว่า "ตอนนี้ฉันอยู่ตรงไหน / ต้องทำอะไรต่อ / ได้อะไรจากการทำ"
* ลดความรู้สึกเหมือนระบบ LMS หรือระบบราชการ
* ใช้ visual language แบบ 8-bit pixel art + cute + bright + pastel
* UI ต้องใช้งานได้จริง ไม่ใช่เพียงภาพ mockup
* รองรับ Desktop, Tablet และ Mobile
* Accessibility ต้องดี อ่านง่าย contrast เพียงพอ keyboard navigation ได้ และรองรับ reduced motion

หลีกเลี่ยง:

# 24. Responsive Design

สร้างอย่างน้อย 3 breakpoints:

Mobile: 360px
Tablet: 768px
Desktop: 1280px

Mobile ต้อง:

* ไม่ horizontal scroll
* navigation ใช้งานง่าย
* cards stack
* CTA อยู่ในตำแหน่งที่เข้าถึงง่าย
* typography readable
* touch target เพียงพอ

# 28. Critical UX Rule

ทุกหน้าที่เป็น authenticated learning surface ต้องมี "next action" ที่ชัดเจน

ผู้เรียนไม่ควรเจอหน้าแล้วไม่รู้ว่าต้องกดอะไรต่อ

ทุกหน้าต้องตอบ:

* Where am I?
* What am I doing?
* What should I do next?
* What did I earn?
* What did I unlock?

สร้าง UI ที่มี visual hierarchy ชัดเจน และมี primary CTA เพียงหนึ่ง action ต่อ context

---

# 29. Final Design Goal

ผลลัพธ์สุดท้ายต้องดูเหมือน:

"Duolingo-style learning progression + 8-bit pixel game + modern educational web app"

แต่ไม่ copy design ของ Duolingo หรือเกมใดโดยตรง

ต้องเป็น visual identity ของ PPGA เอง:

**Cute 8-bit PowerPoint Learning Adventure**

ทำให้ผู้ใช้เปิดหน้า Dashboard แล้วรู้สึกทันทีว่า:

"นี่คือเกมสำหรับเรียน PowerPoint และฉันรู้ว่าภารกิจต่อไปคืออะไร"

สร้าง high-fidelity UI mockups พร้อม reusable components, responsive variants และ clickable prototype
สำหรับ flow หลักทั้งหมด
